### 🚀 Featured Architecture Project

#### **Production-Ready Auto-Healing K8s & Observability Suite**
* **Infrastructure as Code:** Provisioned managed Kubernetes (EKS/AKS) clusters and dedicated network subnets using modular **Terraform** scripts.
* **Automated CI/CD:** Built a **GitHub Actions** pipeline performing zero-downtime rolling updates on every push.
* **Self-Healing & Package Management:** Packaged microservices into versioned **Helm** charts with Liveness and Readiness probes.
* **Full-Stack Observability:** Integrated **Prometheus & Grafana** via Helm to monitor real-time cluster memory, CPU usage, and network traffic.
